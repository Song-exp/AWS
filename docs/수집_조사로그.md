## 3. 2차 재검증에서 발견·수정한 오류 (중요)

### 3.1 SKT 우주패스 × 세븐일레븐 30% → PARTIAL에서 N으로 강등

1차 조사에서 "SKT 우주패스 라이프 세븐일레븐 최대 30%, 일 최대 9,000원"을 PARTIAL로 등록했다. 재검증에서 **원 기사 문맥이 "추석 시즌을 준비 중인 편의점 업계"의 할인 행사**이며, 같은 사안을 다룬 관련 기사(뉴시스·이투데이·뉴시안)가 모두 **추석 선물세트** 판매를 다루고 있음을 확인했다.

즉 이 30%가 **일반 상품 결제에도 적용되는지 불명확**하다. 짠돌이 대학생이 삼각김밥을 살 때 30% 할인을 기대하게 만들면 잘못된 정보가 되므로 N으로 강등하고 적용범위 주의 문구를 명시했다.

### 3.2 굿딜 브랜드별 할인율이 왜 수집 불가인지 공식 확인

"카카오페이 앱 및 카카오톡 카카오페이홈 결제 화면 하단의 결제 수단에서 굿딜을 선택하면 제휴 브랜드와 각각의 할인율을 확인할 수 있다"는 보도를 확인했다. 즉 **브랜드별 할인율은 앱 내에서만 제공**되는 구조가 공식적으로 확인되어, 외부 수집이 불가능한 것이 근거로 뒷받침됐다.

### 3.3 1차 조사에서 날짜로 걸러낸 오류

블로그 검색에서 **"8월엔 카카오페이로 편의점 인기상품 최대 50% 할인"**을 발견했으나, 뉴스 검색으로 출처를 추적한 결과 **인사이트코리아 2023-08-09 기사**였다. 날짜 확인 없이 반영했다면 3년 전 프로모션을 2026년 데이터로 잘못 등록했을 것이다. 이후 모든 행에 `source_date`를 필수 기록했다.

## 5. 조사 방법 (재현 가능하도록 기록)

### 성공한 경로
- **네이버 모바일 뉴스 검색 직접 조회**: `https://m.search.naver.com/search.naver?where=m_news&query=<URL인코딩된 검색어>`
  - **보도일자 + 본문 요약 + 매체명**을 함께 반환해 교차 검증과 시점 확인이 가능했다. 이번 수집의 핵심 경로.
  - 검색어는 **너무 구체적이면 결과가 0건**이 된다. (예: "T멤버십 VIP 등급 편의점 할인 2026" → 0건 / "통신사 멤버십 편의점" → 다수 확보) 넓은 검색어가 유효했다.
- **사업자 공식 고객센터** (help.naver.com): 조건이 텍스트로 정리되어 공식 검증 가능.

### 실패한 경로와 원인
| 경로 | 원인 |
|------|------|
| 데스크톱 네이버 검색(`search.naver.com`) | JavaScript 렌더링으로 최초 HTML에 결과 미포함(161바이트 껍데기만 반환) |
| 통신사 공식 사이트(tworld.co.kr, lguplus.com/benefit) | 동적 렌더링으로 혜택 내용이 HTML에 없음 |
| 카카오페이 공식 사이트(/benefit, /event) | HTTP 404 |
| newsroom.kakaopay.com | DNS 조회 실패 |
| Bing 검색 직접 조회 | 카카오 일반 소개 페이지만 반환 |
| 일반 웹 검색 도구 | 뉴스·핫딜·커뮤니티 노이즈가 대부분 |

### URL 인코딩 주의
1차 시도에서 한글 인코딩을 잘못해 "멤버십"이 "멤버식", "혜택"이 "혜휩"으로 전달되어 결과가 0건이었다. 정확한 인코딩 필요: 혜택 `%ED%98%9C%ED%83%9D`, 멤버십 `%EB%A9%A4%EB%B2%84%EC%8B%AD`

## 6. 결론 및 다음 단계

- **카카오페이 굿딜**을 통해 편의점·음식점·카페 3개 카테고리 모두에 실제 수치가 있는 혜택을 확보했다. (세븐일레븐 최대 10%, 편의점 4사 기본 3%, 치킨 2개 브랜드 3%, 카페 5%)
- 통신사는 **8월 마지막주 유효 여부까지 확인**했다. SKT VIP 해피아워(백미당·쉐이크쉑)는 유효하고, 브랜드 위크의 뚜레쥬르·도미노피자와 영 위크는 이미 종료되어 마지막주엔 적용되지 않는다.
- N 등급 13건은 각 사업자 앱 로그인 후 확인이 필요하다. 앱 내 혜택은 로그인 기반이라 외부 수집이 구조적으로 불가하며, 굿딜의 경우 이 점이 공식 보도로 확인됐다.
- 회기동 실제 입점 브랜드 확인 시 `stores_location.csv`를 실제 지점 기준으로 갱신해야 한다.
