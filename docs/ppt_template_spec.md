# 발표 템플릿 형식 분석 (사용자 제공 PDF 6p 기준 / 작업용)

## 0. 캔버스
- 16:9 와이드스크린 = 13.333in x 7.5in (33.87cm x 19.05cm)
- 배경: 순백 (#FFFFFF)
- 폰트: 한글 고딕 계열. 구현은 `맑은 고딕`(Malgun Gothic) 사용 (윈도우 기본 내장 → 편집 호환성 최우선)

## 1. 모든 슬라이드 공통 골격 (4단 구성)

| 영역 | 위치(대략) | 스타일 |
| --- | --- | --- |
| ① 섹션 라벨 | 좌상단 x=0.62in, y=0.42in | 11pt Bold, 녹색 #00A862. 예: `문제 분석` `전략 제안` `데이터 설명` `모델 소개` `로드맵 정리` |
| ② 메인 헤드라인 | x=0.62in, y=0.72in, 폭 12.1in | 22~24pt Bold, 거의 검정 #111111, 1~2행. **서술 종결형 문장**("~했습니다/~합니다/~입니다")으로 슬라이드 메시지를 한 문장에 담음 |
| ③ 섹션 소제목 + 구분선 | x=0.62in, y=1.95in | 15pt Bold #333333 + 바로 아래 얇은 수평선(#BFBFBF, 0.75pt, 폭 12.1in) |
| ④ 본문 다이어그램 영역 | y=2.35in ~ 6.95in | 박스/표/화살표 조합 |
| 페이지 번호 | 우하단 x=12.4in, y=7.0in | 10pt #808080, 우측정렬 |

> 예외: PDF 3p는 ③ 대신 좌우 2컬럼 헤더(`내부 데이터` / `외부 데이터`)를 각각 Bold + 구분선으로 배치.

## 3. 반복 사용되는 도형 언어(Design Vocabulary)

1. **그레이 헤더 + 라이트 셀 매트릭스** (1p)
   - 상단 열 헤더 = #6E6E6E 채움 / 흰 Bold 글씨
   - 좌측 행 헤더 = #8C8C8C 채움 / 흰 Bold 글씨
   - 본문 셀 = 흰 채움 + #D9D9D9 테두리, 셀 안은 `[ 제목 ]` Bold 1행 + 설명 2~3행 중앙정렬
2. **그린 pill (라운드 사각형)** — `Key Question 1` 처럼 #00B96C 채움 + 흰 Bold, 바로 아래 작은 Bold 캡션
3. **점선 테두리 박스** — #00B96C 대시 테두리 + 흰 채움, 질문/시사점 문구 중앙정렬
4. **딥그린 채움 라벨 + 흰 설명 박스 페어** (2p 우측) — 좌: #00A86B 흰 Bold / 우: 흰 박스 + 그레이 테두리
5. **연결 화살표** — 굵고 짧은 블록형 화살표, 회색(#BFBFBF) 또는 그린(#00B96C). 흐름 방향 좌→우, 위→아래
6. **결론 박스** — 크림 채움 #FFFBF0 + 오렌지 테두리 #F0C060, 안쪽 Bold 3행 중앙정렬 (2p 우하단)
7. **셰브론 프로세스 바** (6p) — 5각형 화살표 모양이 좌→우로 연결, 활성 단계는 그린
8. **번호 배지 + 소제목** (6p) — 검정 정사각 배지에 흰 숫자 + 옆에 Bold 제목 + 그 아래 회색 부제 + 하위 불릿 박스
9. **캡션/출처** — 우하단, 8pt #808080 (5p 논문 인용 방식)
10. **좌측 컬러 바 + 카드 리스트** (3p) — 소스 아이덴티티 색상 세로 바 + 카드명(Bold) + 코드명(작은 monospace 느낌) + 우측 설명 박스

## 4. 톤 & 매너 규칙
- 헤드라인은 **결론부터**. 슬라이드 내용을 요약한 완결 문장.
- 본문은 **명사형 종결** 짧은 구문 위주 (설명형 장문 금지)
- 모든 카드/박스는 **제목(Bold) + 설명(작게, 회색)** 2단 구조
- 정보는 항상 **흐름(→) 또는 매트릭스(행x열)** 로 구조화. 단순 불릿 나열 지양
- 강조는 색으로만. 밑줄/이탤릭 사용 안 함
- 여백 넉넉하게, 박스 사이 gap 0.12~0.2in

## 5. 구현 방침 (python-pptx)
- 표(table)가 필요한 콘텐츠는 `shapes.add_table()` 로 **PowerPoint 네이티브 표** 생성 → 편집 가능
- 위 ①~④ 골격을 함수로 만들어 모든 슬라이드에 일관 적용
- 빈 레이아웃(`slide_layouts[6]`, blank) 위에 직접 배치해 템플릿 잔여 플레이스홀더 제거
